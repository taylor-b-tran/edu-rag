**These are design mockups, not screenshots of the running system.** Each carries a
"BEFORE —" or "AFTER —" banner, and the AFTER images have animation annotations drawn
over them (`slideInRight`, `translateY(-2px) + shadow on hover`, and similar). The
content shown is invented: `Week3_Lecture.pdf` and `DBNotes_Joins.pptx` are not in the
corpus, and the model badge reads `ollama/llama3`.

Do not use them as evidence that a feature works. For that, capture the real UI.
`docs/a3_interface_demo/` holds actual screenshots of the running application.

One thing they do document usefully: the BEFORE welcome screen shows the four hardcoded
suggested prompts that T8-07 removes.
