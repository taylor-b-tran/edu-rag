## Project Overview

EduRAG is an AI-powered educational assistant designed to help university students interact with course materials in a natural, conversational way. Students often struggle to locate relevant information across lecture slides, textbooks, and course notes using traditional keyword-based search — EduRAG solves this by understanding the meaning behind questions, not just the words.

Using **Retrieval-Augmented Generation (RAG)**, the system retrieves the most relevant sections from a curated collection of course materials and passes them as context to a Large Language Model (LLM), which then generates accurate, context-aware responses. The result is a smart assistant that can answer questions, provide explanations, and summarise content — all grounded in real course documents.

The project is developed as part of **CSIT321** at the University of Wollongong, supervised by **Prof. Jun Yan**.
